One line, at most 200 characters, about a small good thing that happened today — a neighbour's cat, after a year of ignoring me, headbutted my ankle this morning and waited purring by the gate until I opened it for her. Warm, a little surprising, one concrete detail: written to make the judge smile.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (UTF-8, no trailing newline) and verifies the write round-trips byte for byte.
